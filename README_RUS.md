# Морской бой

Браузерная игра «Морской бой» — сразитесь с ИИ-противником на классическом поле 10×10.

https://battle-ship-vergiene.netlify.app/

![Скриншот игры](/docs/screenshot.png)

## Технологии

- Vanilla JavaScript (ES-модули)
- Vite (сборка / dev-сервер)
- CSS Grid (расположение поля и легенды)
- SVG-иконки из [Lucide](https://lucide.dev/)
- Развёрнуто на Netlify

## Архитектура

Игровая логика разделена на три класса с чёткими зонами ответственности. `Ship` отвечает только за собственный размер, ориентацию и состояние попаданий — ему ничего не известно о своём положении на поле. `Board` владеет сеткой и является единственным источником истины о расположении кораблей: проверяет размещение (границы, пересечения, соседство), фиксирует атаки и сообщает состояние клеток. `Player` (и его подклассы `HumanPlayer` и `AIPlayer`) отвечают только за то, *какой ход сделать* — разместить корабль или атаковать координату — и никак не связаны с отрисовкой или хранением сетки. Отрисовка вынесена в отдельный слой (`render.js`), который читает состояние `Board` и рисует его; сам `Board` ничего не знает о DOM.

## Запуск локально

```bash
git clone https://github.com/vergiene/battle-ship.git
cd battle-ship
npm install
npm run dev
```
